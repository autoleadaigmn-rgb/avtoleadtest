CLEAR EXPECTATIONS

Built around the way
your shop handles inquiries.

Try the workflow before discussing a production setup.

Is this using a live AI model?+

No. It uses local rules, multi-field extraction and a flexible request flow. You can correct details without starting over. It does not use a generative AI model, voice calling or a live scheduling connection.

Where do the requests go?+

With your consent, the suggested fictional test details are sent over HTTPS to an AutoLead Google Apps Script server, saved in a separate private Demo Requests Google Sheet, and emailed to the verified AutoLead Gmail owner. A copy is saved in this browser. Real contact data is rejected. Local preview stays on this device. The protected Owner dashboard reads server requests after Google authorization.

Can it diagnose a vehicle or confirm a booking?+

No. It collects the customer’s description for a service advisor. It does not diagnose safety issues, quote repair prices, or promise an appointment.

What would a real deployment need?+

Verified shop information, a secure shared inbox or CRM connection, consent and retention settings, and testing with the shop. Live AI, voice, and scheduling integrations would be agreed separately. This demo makes no claims about real customers or results.

TEST DATA NOTICE · VERSION 1

Local previews. Separate fictional server tests.

This test sends service, vehicle, sample description, preferred time, sample name and contact, request ID, and consent time to AutoLead AI using Google Apps Script. The owner stores accepted tests in a separate private Google Sheet and receives an email in Gmail. Google processes these records in the owner’s account. No real shop receives them and no appointment is booked.

You can try arbitrary names, vehicles, concerns and contact formats locally. Local previews stay in this tab’s memory and disappear on reload. Prefer fictional contacts. Only the separate server test accepts Alex Demo, alex@example.com, 2019 Toyota Camry, and the supported sample concerns and times. Other data is rejected before it is stored or emailed by the server. Up to three accepted tests per UTC day are allowed across all visitors. Identical requests within 24 hours are not saved or emailed again.

Local free-text previews remain in tab memory only. Browser storage contains only fixed fictional server-test receipts. Local deletion does not delete the server record or email. The owner should remove test rows and notification emails after review, within seven days. For questions or deletion requests, contact autolead.ai.gmn@gmail.com. This notice is for testing; public collection of real personal data remains disabled until the owner approves production settings and a privacy policy.
