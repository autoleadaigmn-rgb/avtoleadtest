# Starter 2.0 isolated Cloudflare test

This deployment is independent of GitHub Pages, Google Sheets CRM and the original Apps Script. Only branch `starter-2-test` is used. Public test URL: https://autolead-starter2-test.autolead-ai-gmn.workers.dev/install-test.html. The two fictional shop selectors are `bayline` and `cedar-ridge`.

The Cloudflare account is on Workers Free. Two D1 Free databases exist: `starter2-bayline-test` and `starter2-cedar-ridge-test`; each received `migrations/0001_initial.sql`. The Worker is `autolead-starter2-test`. It uses the `workers.dev` address, static assets, and one scheduled trigger every 15 minutes. No paid service, AI model, or real email adapter is attached.

Safety configuration is `MODE=TEST_ONLY`, `MAIL_TRANSPORT=SIMULATED`, and a server-only `SESSION_SECRET` stored as a Cloudflare Worker secret. The public request endpoint accepts only one fixed fictional fixture per shop. Typed chat messages remain in the browser. The real owner sign-in is deliberately unavailable: `GOOGLE_CLIENT_ID=NOT_CONNECTED`, `OWNER_MEMBERSHIPS={}`. No owner records are public. Do not set arbitrary owner membership or weaken token verification to make a demo login work.

From this directory, run `pnpm test` and `pnpm check` before updating the test Worker. The ignored `wrangler.test-cloud.jsonc` is generated with `pnpm prepare:cloud-test <BAYLINE_D1_UUID> <CEDAR_D1_UUID>` after fresh D1 creation. Do not regenerate if the existing account resources are already present. The config is ignored because it is account-specific; it contains no secrets. The published Worker can be verified with `node tools/cloud-smoke.mjs https://autolead-starter2-test.autolead-ai-gmn.workers.dev`, which sends only two fixed fictional requests and checks idempotency, cross-shop session rejection, arbitrary-contact rejection, and owner fail-closed behavior. This smoke test creates new test records on each run.

To inspect storage without exposing payloads, use `pnpm exec wrangler d1 execute starter2-bayline-test --remote --command "SELECT count(*) AS n FROM requests" --json --config wrangler.test-cloud.jsonc` and repeat for the Cedar Ridge database. `outbox` is written in the same SQLite statement as the request. The scheduled handler processes simulated deliveries and retention. A local test suite covers transient failures, retries, duplicate delivery prevention, expiration, and deletion ledgers. Cloud data retention is 90 days for fictional requests; scheduled deletion runs every 15 minutes.

To pause the test intake, set `INTAKE_ENABLED` to `false` in the ignored cloud config and deploy that config. To roll back test code, use Wrangler's deployment rollback for `autolead-starter2-test`; do not switch or merge the GitHub `main` branch. Do not delete the D1 databases during code rollback. Real owner login requires a Google Web OAuth client registered for this exact HTTPS origin and verified owner-subject membership; set these server-side only after review. Real contacts, real email delivery, and any paid plan remain out of scope.
