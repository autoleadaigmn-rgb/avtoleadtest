What happens to test data?

This is a fictional Bayline Auto Care demonstration, not a real repair business or a production privacy policy.

Your typed chat stays in this tab and disappears when the page is reloaded. Do not enter real personal data. The server only accepts the exact fictional Alex Demo fixture, after you tick the consent checkbox and press the separate test-save button.

The test record includes the fictional name, contact, vehicle, concern, preferred time, resolved date, consent version and server timestamp. Separate databases isolate the test shops. Only an authorized owner can read, update or delete records. Notifications are simulated in the same test database. No email is sent.

Records expire 90 days after submission and are removed when scheduled maintenance runs. The local lab does not schedule unattended maintenance; the owner can run it from the panel. Deleted request IDs remain in a 30-day deletion ledger without contact fields to prevent accidental resurrection. A local snapshot may contain fictional records; delete snapshots when no longer needed. Restoring a snapshot must include the latest deletion ledger.

Loading a hosted widget exposes technical network metadata such as IP to its hosting provider before you submit anything. The server uses short-lived hashed network/session rate buckets, removed by maintenance. No transcript is stored, no marketing is sent, and there are no analytics or advertising cookies.

Production collection remains disabled. Before a real launch, the actual business identity, privacy contact, processing agreement, subprocessors, locations, retention and access arrangements must be reviewed and approved.
